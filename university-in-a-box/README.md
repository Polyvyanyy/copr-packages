# University in a Box · 日本語

Русскоязычный веб-продукт для самостоятельного изучения **письменной основы японского**: занятия, карточки, контролируемое письмо, гостевой режим и аккаунты с серверным сохранением. Реализованы подписка на размещённый сервис, управление аккаунтом, обращения в поддержку и публичные страницы условий. Это не аккредитованный университет и не полный курс владения японским языком.

**Публичный коммерческий запуск ещё не подтверждён.** Не назначен реальный оператор, не проведены юридическая и независимая предметная проверки, не подтверждены рабочие ключи и полный цикл реальных платежей и писем. Установка кода и зелёные тесты не закрывают эти зависимости; перечень действий — в [OPERATIONS.md](OPERATIONS.md).

## Запуск и проверки

Нужен Node.js `^24.15.0 || >=26.0.0`, как указано в `package.json`; для постоянного сервера предпочтительна ветка 24 LTS. Команды выполняются из каталога приложения:

```sh
cd university-in-a-box
npm ci
npm run dev -- --host 0.0.0.0 --port 3000
```

Один Node.js-сервер обслуживает API и Vite middleware с HMR. В Hoplite эти же команды записаны в `../.hoplite/settings.json`: Preview использует dev-сервер, а не подмену production-сборкой.

Для разработки `.env`, платёжные ключи и внешняя БД не нужны. SQLite, секрет локальной аутентификации и журнал писем создаются в закрытом `server/data/`, исключённом из Git. Это реальные локальные аккаунты; в development подтверждение почты не является условием входа, а письма **не отправляются наружу**. Не используйте здесь production-данные и не публикуйте журнал со ссылками подтверждения. `.env.example` — намеренно незаполненный шаблон **production**, а не готовый файл для локального запуска.

```sh
npm run test          # все доменные, компонентные и серверные тесты
npm run test:server   # только серверные тесты
npm run build         # TypeScript без эмиссии и сборка интерфейса Vite в dist/
npm run check         # npm run test && npm run build
npm run format:check  # проверка Prettier
```

`npm start` запускает production-сервер: нужны предварительная сборка, постоянная база и заполненное серверное окружение. Подробные требования, шаблоны systemd/Caddy и команды `npm run ops -- ...` приведены в [OPERATIONS.md](OPERATIONS.md). Одна статическая публикация `dist/` не предоставляет аккаунты, синхронизацию и платежи.

## Учебная программа

Редакция `written-foundations-2026.1` содержит **40 уроков и 200 заданий** с фиксированными ключами: по пять заданий на урок. Дополнительно есть пять диагностических вопросов, 246 карточек, справочник каны и четыре контролируемых письменных задания.

| Раздел                         | Занятия | Охват                                                                                            |
| ------------------------------ | ------: | ------------------------------------------------------------------------------------------------ |
| Хирагана и запись              |      15 | 46 базовых знаков, диакритики, сочетания с малыми знаками, малый っ, долгота и короткие слова    |
| Катакана                       |      13 | 46 базовых знаков, диакритики, малые формы, ー, похожие знаки и ограниченный набор заимствований |
| Контролируемое чтение и письмо |      12 | Первые письменные модели, выбранные кандзи, короткие тексты и представление по образцу           |

Справочник `/kana` сопоставляет хирагану, катакану и письменную транскрипцию в 29 строках. «Полная базовая кана» не означает все исторические знаки, все способы передачи заимствований или владение произношением.

Пять учебных ролей — названия инструментов, **не живые преподаватели и не AI-агенты**:

| Роль      | Реализация                                                                        |
| --------- | --------------------------------------------------------------------------------- |
| Adviser   | Настройка учебного ритма, пять диагностических вопросов и рекомендация по ответам |
| Librarian | Реестр пяти источников, лицензии, атрибуция, поиск и закладки                     |
| Tutor     | Уроки, фиксированные задания, подсказки, разборы и повторение карточек            |
| Editor    | Четыре письменные модели с явными условиями, черновик и история версий            |
| Roommate  | Три фиксированные аналогии с оговорёнными ограничениями и личными заметками       |

У Editor проверяются только объявленные условия: две проверки у представления и по три у остальных заданий. Это не оценка свободного текста, смысла, естественности японского или всей грамматики. У каждого задания свой черновик; версии связаны с заданием, а общий лимит истории составляет 100 записей. Это учебная практика, не проверенное преподавателем портфолио.

### Что означает прогресс

- Процент относится к **40 урокам этой редакции**, а не ко всему японскому языку и не к уровню JLPT.
- Прохождение требует полной попытки с результатом не ниже 80% без встроенных подсказок. В режиме «Проверь меня» ключи открываются после всех ответов.
- «Повторено с отсрочкой» означает две такие попытки с интервалом не меньше семи дней. Задания остаются фиксированными: это самопроверка, не независимый экзамен.
- Самооценка карточек влияет на расписание повторений, но не подтверждает прохождение урока. Дни активности учитываются отдельно от результатов.
- Материалы подготовлены с помощью ИИ и зафиксированы; `reviewState` — `not-independently-reviewed`. **Независимой рецензии преподавателя японского пока нет.**

В приложении нет аудиокурса, распознавания или оценки речи, разговорного тренажёра, проверки рукописных штрихов, сертификации и аккредитации. Нет генерации или обращений к языковым моделям в runtime. Расход на AI API здесь — $0; это не оценка себестоимости хостинга, почты, эквайринга, поддержки и редакторской работы.

## Открытые материалы и платный сервис

Подписка оплачивает **серверное хранение и синхронизацию учебных данных**, а не исключительные права на контент. Все открыто лицензированные материалы остаются доступными для чтения без оплаты; подписка не отменяет права на их копирование и адаптацию по соответствующей лицензии.

| Режим                    | Учебные данные                                                                                                        |
| ------------------------ | --------------------------------------------------------------------------------------------------------------------- |
| Гость                    | Бесплатная локальная практика и сохранение в браузере, без аккаунта и серверной синхронизации                         |
| Первые 7 дней аккаунта   | Чтение и запись в облачное хранилище; trial начинается при создании аккаунта, карта не нужна                          |
| После trial без подписки | Чтение ранее сохранённого, экспорт, удаление и сброс остаются доступны; новые учебные серверные сохранения недоступны |
| Подписка $20 USD / месяц | Серверное сохранение и синхронизация, пока провайдер подтверждает действующий доступ                                  |

Окончание trial **не запускает списание**. Подписку оформляют отдельно через Stripe Checkout; управление оплатой и отмена следующего продления доступны в Customer Portal. При отсутствии платёжной конфигурации оформление отключено, а не имитируется. Сам переход на страницу успешной оплаты не выдаёт доступ: состояние подтверждается сервером через провайдера. Подключение и проверка реального платёжного аккаунта ещё необходимы.

## Хранение, перенос и безопасность данных

Гостевое состояние хранится в `localStorage` под ключом `university-in-a-box:japanese:learning:v1`. Очистка данных браузера удаляет эту копию. Для гостевых записей нет облачной резервной копии и согласования одновременного редактирования в нескольких вкладках.

После входа источник данных — SQLite на сервере. При сохранении передаётся `revision`; устаревшая ревизия возвращает конфликт `409`, а интерфейс предлагает выбрать серверную версию или изменения этой вкладки. Автоматического слияния нет. При сетевой ошибке неподтверждённые изменения остаются **только в памяти вкладки**: их нужно сохранить или экспортировать до закрытия. Аккаунтный режим не является полноценным offline-first хранилищем.

Гостевые записи не отправляются в аккаунт автоматически. В `/account` предусмотрен отдельный перенос с подтверждением **замены**, не слияния; для серверной записи нужен активный trial или подписка. Экспорт/импорт учебного JSON доступен в `/progress` и позволяет вручную переносить состояние между браузерами и режимами. Полный экспорт аккаунта в `/account` — отдельный архив профиля, согласия, подписки, учебных данных и обращений, а не файл для импорта прогресса.

Формат учебного состояния остаётся `version: 1`, независимо от редакции содержания. Импорт проверяет формат, размеры и известные идентификаторы; баллы пересчитываются по ключам. Повреждённые записи не становятся доказательством прохождения. История ограничена 500 попытками с сохранением подтверждений статусов, 100 версиями текста и 1000 датами активности. Для собственного долгосрочного архива нужен регулярный экспорт. Данные, даже сохранённые на сервере, не являются независимой аттестацией.

Аккаунт позволяет изменить имя и пароль, отозвать другие сессии, экспортировать данные и запросить удаление. Действующую или неоплаченную подписку сначала необходимо урегулировать у провайдера: удаление аккаунта не подменяет отмену платежей. Удаление рабочей базы аккаунта не удаляет автоматически резервные копии и обязательные записи провайдера; сроки и процедуру обязан определить оператор.

## Маршруты и устройство проекта

- Публичное описание: `/welcome`; подписка: `/membership`; помощь: `/help`; документы: `/legal/terms`, `/legal/privacy`.
- Аккаунт: `/auth/sign-in`, `/auth/sign-up`, `/auth/forgot-password`, `/auth/reset-password`, `/onboarding`, `/account`.
- Учёба: `/`, `/plan`, `/lesson/:lessonId`, `/kana`, `/practice`, `/progress`, `/library`, `/writing`, `/connections`.

`src/domain/` содержит учебные данные, источники, рубрики и правила прогресса; `src/pages/` — страницы; `learning-context.tsx` и `product-context.tsx` — гостевое состояние, синхронизацию и состояние аккаунта. `server/` содержит Express API, Better Auth, почту, оплату, SQLite-миграции и операционный CLI. Контракты клиента и API определены в `src/product-types.ts`.

Production рассчитан на **один Node.js-процесс, один origin и постоянный локальный SQLite-диск**. WAL, транзакции и ревизии не заменяют общую БД для нескольких узлов. Горизонтальное масштабирование, высокая доступность и измеренная нагрузочная ёмкость не заявлены. Развёртывание, резервирование и ограничения — в [OPERATIONS.md](OPERATIONS.md).

## Источники и проверка качества

Оригинальные учебные материалы распространяются по CC BY 4.0. Подробная атрибуция пяти источников, границы использования внешних материалов и лицензии ассетов — в [CONTENT_SOURCES.md](CONTENT_SOURCES.md) и `/library`. Словарные выгрузки EDRDG и материалы NC/ND не импортированы. Шрифты и иконки поставляются локально; приложение не использует CDN для шрифтов и изображений.

Доменные тесты проверяют структуру курса, каны и рубрик, оценивание, отсрочку, импорт и ограничение истории. Компонентные и серверные тесты проверяют обработчики и контракты аккаунта, синхронизации и операций. Они не заменяют независимую предметную рецензию, проверку в браузере, испытания доставки писем и платежей у настоящих провайдеров. Доступность с клавиатуры и мобильные сценарии нужно проверять через Preview; список обязательных условий запуска остаётся открытым в [OPERATIONS.md](OPERATIONS.md).
