# University in a Box · 日本語

Рабочий локальный MVP японского кампуса с русским интерфейсом. В приложении нет каталога других направлений. Только письменность, чтение коротких записей и письменная практика.

## Запуск

Нужен Node.js 24.15+ в ветке 24 LTS либо 26+.

```sh
cd university-in-a-box
npm ci
npm run dev -- --host 0.0.0.0 --port 3000
```

В Hoplite эти же команды записаны в `../.hoplite/settings.json`: Preview запускает dev-сервер, а не production-сборку. Ключи, переменные окружения и внешняя база данных не нужны.

```sh
npm run check         # доменные и компонентные тесты, TypeScript, сборка
npm run format:check  # форматирование исходников
```

## Что работает

| ALTER     | Реализация                                                                                      |
| --------- | ----------------------------------------------------------------------------------------------- |
| Adviser   | Учебный ритм, пять диагностических вопросов и консервативная рекомендация по конкретным ответам |
| Librarian | Реестр источников, атрибуция, лицензии, поиск и закладки                                        |
| Tutor     | Семь занятий, 35 заданий с фиксированными ключами, разборы, подсказки и 24 карточки             |
| Editor    | Черновик, проверка двух явных условий письменного задания, сохранение и восстановление версий   |
| Roommate  | Три фиксированные аналогии с явными ограничениями и личными заметками                           |

Маршруты: `/`, `/plan`, `/lesson/:lessonId`, `/practice`, `/progress`, `/library`, `/writing`, `/connections`. Навигация, поиск и диалоги доступны с клавиатуры; мобильный интерфейс использует отдельное меню.

## Прогресс без завышенных обещаний

- Процент относится только к **семи занятиям версии 1**, не ко всему японскому языку.
- Прохождение требует полной попытки с результатом не ниже 80% и без встроенных подсказок. Ключи в режиме «Проверь меня» показываются только после всех ответов.
- «Повторено с отсрочкой» означает две такие попытки с интервалом не меньше семи дней. Задания фиксированные; это учебная самопроверка, не экзамен, сертификация или подтверждение языкового уровня.
- Самооценка карточек меняет только их расписание. Активные дни учитываются отдельно от результатов занятий; повторение карточки не стирает предыдущий день активности.
- Проверка Editor ищет заданную конструкцию, но не оценивает имя, смысл текста или всю грамматику. Заметки Roommate не оцениваются.

## Локальные данные

Состояние хранится в `localStorage` под ключом `university-in-a-box:japanese:learning:v1`. Экспорт и импорт JSON доступны на странице прогресса. Импорт заменяет данные только после подтверждения; неправильные версии, слишком большие файлы и повреждённые записи не принимаются. Баллы пересчитываются по ключам, а не берутся из импортированного поля результата.

Хранилище ограничено: до 500 попыток с сохранением подтверждений достигнутых статусов, 100 версий текста и ограниченный журнал дней активности. Для долгосрочного архива нужен регулярный экспорт. Не используйте экспорт как доказательство независимой аттестации: все данные контролируются пользователем браузера. Одновременное редактирование в нескольких вкладках и облачная синхронизация не реализованы.

## Границы MVP

- Нет платежей, аккаунтов, сервера персональных данных и облачного переноса. `$20 / месяц` в информации о кампусе — планируемая цена, не действующая подписка.
- Нет запросов к языковым моделям в runtime: расход на AI API в этой реализации — **$0**. Оценки будущих расходов из продуктового плана не являются замерами этого приложения.
- Материалы подготовлены с помощью ИИ и зафиксированы. **Независимая предметная рецензия ещё не проведена.** Пилот нельзя выдавать за готовую академическую программу; название не подразумевает аккредитацию или выдачу дипломов.
- В конце программы часть конструкций вводится как готовые письменные образцы. Полная кана, перенос собственного имени, сложные тексты и широкий языковой уровень не покрываются.

## Проверка

Доменные тесты проверяют структуру курса и лицензии, оценивание, подсказки, границы отсрочки, повторяющиеся ID, импорт, ограничение истории и журнал активности. Компонентные тесты проходят реальные обработчики: проверку урока, карточки, черновик, заметки, закладки, смену ритма, импорт и подтверждение сброса. Визуальную и клавиатурную проверку нужно выполнять в браузере через Preview; эмуляция DOM не заменяет её.
